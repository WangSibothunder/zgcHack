# Demo Scope：转院病历时间轴重建

## 一句话定位

把转院患者携带的杂乱外院材料整理成可浏览、可核验、可追溯的病情时间轴，帮助接诊医生快速建立既往诊疗上下文。

## 核心演示故事

患者带着外院纸质材料来到目标医院；导诊人员批量上传材料；系统展示处理状态并生成时间轴；接诊医生浏览节点、筛选关键材料、打开原图核验提取字段，并查看可能需要补充的材料清单。

## Demo 只验证六件事

1. 外院材料能被模拟上传并转换为时间轴。
2. “一个日期一个节点”的横向结构比图片列表更容易快速浏览。
3. 概要能够回到合成原图和 OCR 证据位置。
4. 异常标记和低置信度提示是清晰、可核验的。
5. 医生能筛选与转院原因相关的节点。
6. 系统能提示材料组织层面的缺失项。

## 明确不做

- 诊断推理、治疗方案、风险分层。
- 真实病例上传和真实医院联通。
- HIS/EMR 接口接入。
- 生产级账号、权限、审计、隐私合规落地。
- 慢病档案和长期健康管理。

## 演示口径

系统展示的是“材料整理结果”和“证据回溯路径”，并非诊疗结论。所有 Demo 内容均为合成材料。
